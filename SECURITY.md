# Security

This is an experimental lab prototype. The TCP service is unauthenticated and unencrypted. Do not expose it to the internet or untrusted networks. Do not forward its ports through a router. Use an isolated network and only authorized equipment.

Never commit configured Wi-Fi passwords, private keys, packet captures, local build trees, or raw wireless discovery logs. Keep credential-bearing sketches local. Use placeholder credentials in distributed source.

The framed route is a diagnostic interface, not a security boundary. The legacy interactive shell is separate. A successful frame does not prove command success. Session recovery and authentication remain open work.

Please report security concerns privately to the repository maintainer using GitHub's private vulnerability reporting if enabled; otherwise request a private contact channel without publishing sensitive details.
